=====================================
SUMMARY OF KEY TECHNOLOGIES
=====================================

Backend (API):
  - NestJS (TypeScript)
  - Prisma ORM
  - JWT Authentication
  - Socket.io (WebSockets for notifications)
  - Cron Jobs
  - Email Service

Face Recognition Service:
  - Python FastAPI
  - Face recognition with enrollment & verification

Frontend (Web):
  - Next.js 13+ (App Router)
  - TypeScript/TSX
  - Tailwind CSS
  - PostCSS
  - Zustand (state management)
  - ShadcN UI Components

Database:
  - Supports multiple database systems (via Prisma)
  - Seed data available

Core Features:
  - User Authentication & Authorization
  - Employee Management
  - Attendance Tracking (with facial recognition)
  - Geo-fencing
  - Expense Management
  - Invoice Management
  - Leave Management
  - Salary Management
  - Audit Logging
  - Comments System
  - Request Management
  - Reports
  - Notifications (Real-time via WebSockets)
